# 数据与备份

实例数据由assetmanager.db、account.db、media/和attachments/组成。不要把这些文件提交至公开仓库。浏览器中的主题和趋势布局按origin存储；趋势统计缓存按账号、资产数据、日期和算法版本验证，退出登录时清理。缓存不能代替服务端数据或备份。

在设置中的“备份与恢复”导出完整ZIP，包含正常资产、分类、标签、附属关系、图片和附件，不包含回收站、账号密码和WebDAV密码。恢复前先预览，再选择合并或替换；合并跳过已有ID，替换仍保留本地回收站。保管导出的ZIP，它可能包含私人备注、图片和原始迁移资料。

旧平台备份在部署设备上解密，使用用户提供的密码，或部署者自行保管的DATA_DIR/legacy-backup.key。项目不提供密钥。未经本人授权不要处理他人的备份。

WebDAV是手动备份：需要预先存在的文件夹及PROPFIND、PUT、GET、MOVE、DELETE支持。写入临时文件、回读校验后再覆盖keeps-backup.zip。云端覆盖本地先下载和预览再确认。当前仅保留一份远端包，无自动同步或历史版本保留。

附件上限30MB；导入包上限512MB、解压上限2GB和10,000文件。服务端图片保留展示图和压缩原图；不会因为状态水印修改用户原图。
